# Phase 02.5 Plan 01: Manifesto Schema & Data-Flow Wiring Summary

Added 3 image_picker + 3 text Shopify schema settings and threaded their resolved values through 6 new data-* attributes into main.tsx as 6 new React props on `<HomepageScrollytelling />`, establishing the prop contract Plan 02 will consume.

## What Was Built

**Task 1 — `sections/hero-canvas.liquid`:**
- Added a new `"Manifesto — 3-Panel Reveal"` header block in the `{% schema %}` settings array, placed immediately after the existing `"About Us — Group 3"` group.
- Added 3 `image_picker` settings (`manifesto_image_1`, `manifesto_image_2`, `manifesto_image_3`), each with a label identifying its panel ("Panel 1 Image (The Race)", etc.) and deliberately no `default` key (per D-04 — no source images exist on disk yet).
- Added 3 `text` settings (`manifesto_tagline_1/2/3`) with exact reference copy defaults: `"THE RACE."`, `"THE MOMENT."`, `"YOURS."`.
- Added 6 new `data-*` attributes on `#homepage-interactive-root`, immediately after the existing `data-wordmark-footer-url` attribute:
  - `data-manifesto-image-1/2/3` resolve via `{% if ... != blank %}{{ ... | image_url: width: 1600 }}{% endif %}` (empty string when no image assigned — no fallback asset path supplied, per the blocker).
  - `data-manifesto-tagline-1/2/3` resolve via `{{ ... | default: 'FALLBACK' | escape }}` with matching fallback text per panel.

**Task 2 — `src/main.tsx`:**
- Added 6 new `const` attribute reads in `bootstrap()`, immediately after the existing `exploreCta` read: `manifestoImage1/2/3` (fallback `''`) and `manifestoTagline1/2/3` (fallback `'THE RACE.'` / `'THE MOMENT.'` / `'YOURS.'`).
- Passed all 6 values as new props on the `<HomepageScrollytelling ... />` JSX call, after the existing `exploreCta={exploreCta}` prop.
- Did not modify `HomepageScrollytellingProps` in `HomepageScrollytelling.tsx` — that interface update and the temporary excess-prop TypeScript warning are explicitly deferred to Plan 02 per the plan's scope.
