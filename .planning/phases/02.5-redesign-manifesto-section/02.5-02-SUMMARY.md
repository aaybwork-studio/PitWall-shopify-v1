# Phase 02.5 Plan 02: Manifesto 3-Panel Image Reveal Summary

Replaced the text-only Manifesto section (quote, corner-bracket frame, divider, stat row) in both desktop and mobile JSX of `HomepageScrollytelling.tsx` with 3 full-bleed image panels showing difference-blended DOM taglines ("THE RACE." / "THE MOMENT." / "YOURS."), staggered scale-up-from-center reveal on desktop, and vertically stacked panels on mobile — consuming the prop contract established in Plan 01.

## What Was Built

**Task 1 — Props, motion value, and video gate (`src/components/HomepageScrollytelling.tsx`):**
- Added 6 new optional fields to `HomepageScrollytellingProps` (`manifestoImage1/2/3`, `manifestoTagline1/2/3`) with matching destructured defaults (`''` for images, `'THE RACE.'`/`'THE MOMENT.'`/`'YOURS.'` for taglines).
- Added `manifestoProgressMV` motion value plus `manifestoPanelOpacity`/`manifestoPanelScale` `useTransform` derivations, and a `manifestoRevealed` boolean state flag.
- Added a `useEffect` (keyed on `[scrollTop, vh]`) that computes Manifesto's own arrival progress (`start = vh*0.7`, `end = vh*1.3`) from the existing scroll state, sets `manifestoProgressMV`, and flips `manifestoRevealed` to `true` once progress crosses 0.05.
- Lowered the fixed `<VideoBackground>` gate threshold from `vh * 2.3` to `vh * 1` per D-15.

**Task 2 — Desktop 3-panel reveal (`src/components/HomepageScrollytelling.tsx`, `src/index.css`):**
- Added `.manifesto-panel` / `.manifesto-panel.reveal-active` CSS pair to `index.css` (opacity 0→1, transform scale 0.88→1, 0.8s cubic-bezier easing) modeled on the existing `.reveal-dashboard-item` pattern.
- Replaced the entire desktop Manifesto block (old quote/corner-bracket/divider/stat content) with 3 sibling `33.333vw` full-height panels, each containing a lazy-loaded full-bleed `<img>` and a `mixBlendMode: 'difference'` tagline `<span>` positioned per D-11 (panel 1 top-left, panel 2 centered, panel 3 bottom-right). Staggered `transitionDelay` values: `0ms` / `130ms` / `260ms`.

**Task 3 — Mobile stacked panels (`src/components/HomepageScrollytelling.tsx`):**
- Replaced the mobile Manifesto `<section>` (including its per-section `<VideoBackground>` and old quote/frame/stat content) with 3 stacked `<section className="manifesto-panel ... reveal-active">` blocks, each `h-[55vh]`, with the same difference-blended tagline positioning logic scaled to mobile padding (`top-6`/`left-6`, centered, `bottom-6`/`right-6`).
- No `<VideoBackground>` remains inside any of the 3 new mobile Manifesto sections.

**Rule 1 fix — TypeScript build error:**
- After Tasks 2-3 removed the old Manifesto JSX, `stat1Value`/`stat1Label`/`stat2Value`/`stat2Label`/`stat3Value`/`stat3Label` (no longer referenced anywhere) and `manifestoPanelOpacity`/`manifestoPanelScale` (defined but unused since the simpler CSS-class reveal was used instead) tripped `noUnusedLocals`/`noUnusedParameters` and failed `tsc`. Fixed by adding `void` reference statements rather than deleting the props/values, preserving the public prop contract (stat props remain valid schema-driven inputs from Plan 01's prior phase) while satisfying TypeScript strictness. Rebuilt `assets/main.css` and `assets/pitwall-interactive.js` to reflect the source changes.
