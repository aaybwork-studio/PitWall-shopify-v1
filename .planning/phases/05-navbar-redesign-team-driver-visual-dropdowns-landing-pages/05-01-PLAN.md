| T-05-01 | Tampering | `block.settings.link` (url setting) rendered into `href` | accept | Shopify's `url` setting type only accepts internal/external URLs validated by the theme editor UI; no raw user input reaches this from storefront visitors — merchant-only trust boundary, same risk profile as existing hardcoded links |
| T-05-02 | Information Disclosure | `block.settings.team_name` / `driver_name` rendered via `{{ }}` (Liquid auto-escapes by default) | accept | Liquid's default output filter HTML-escapes string output; no `| raw` filter used in this plan, so XSS via block text settings is not introduced |
</threat_model>
