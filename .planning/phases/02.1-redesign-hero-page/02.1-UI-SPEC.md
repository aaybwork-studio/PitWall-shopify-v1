## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Small icon gaps, inline badge padding |
| sm | 8px | Marquee label gaps, small text margins |
| md | 16px | Internal mobile card padding, default element spacing |
| lg | 24px | Internal desktop card padding, standard section margins |
| xl | 32px | Grid gaps, layout column spacing |
| 2xl | 48px | Mobile section headers, margins |
| 3xl | 64px | Desktop section gaps, header offset spacing |

Exceptions: Card corner radius of **10px** is specified as a visual style override for homepage cards.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` / `var(--fg)` | Mode-adaptive background (Hero: dark; Manifesto: light/dark; Collection: dark/light; About Us: light/dark) |
| Secondary (30%) | `#FFFFFF` | Background for the floating white cards |
| Accent (10%) | `var(--accent)` (`#F6C917`) | Hover states, button backgrounds, marquees, pre-order badges |
| Destructive | `#FF0000` | Errors or destructive warnings |

Accent reserved for: Hover highlights, primary CTA buttons (e.g. SHOP NOW, OUR STORY), marquee ticker accents, and pre-order badges.
