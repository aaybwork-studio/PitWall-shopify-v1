# Phase 02.1: Redesign Hero Page - Research Findings

## CSS Snap-Scroll Architecture

### 1. Desktop Snap Behavior (768px and up)
CSS scroll snapping is the most performant, responsive, and cross-browser compatible method for height-locked layouts. It avoids scroll-jacking jank.
To ensure the global footer is reachable, the scroll container must be applied to the `html` element on the index page rather than a nested wrapper inside `MainContent`.
- **Targeting the Homepage:** We can target the homepage by adding a class to the `<body>` or `<html>` element (e.g. `homepage-snap`) in `layout/theme.liquid` (which we can dynamically output using `{% if template == 'index' %}homepage-snap{% endif %}`).
- **CSS Setup:**
  ```css
  @media (min-width: 768px) {
    html.homepage-snap {
      scroll-snap-type: y mandatory;
      scroll-behavior: smooth;
      height: 100%;
      overflow-y: scroll;
    }
    
    html.homepage-snap body {
      height: 100%;
    }
    
    .snap-section {
      height: 100vh;
      scroll-snap-align: start;
      scroll-snap-stop: always;
      position: relative;
      overflow: hidden;
    }
    
    /* Separator Video Player is 1/3 viewport height, but acts as a snap target */
    .separator-video-container {
      height: 33.333vh;
      scroll-snap-align: start;
      scroll-snap-stop: always;
      position: relative;
      overflow: hidden;
    }
    
    /* Snaps the global footer to the bottom of the viewport */
    .footer-section {
      scroll-snap-align: end;
    }
  }
  ```

### 2. Mobile Fallback (below 767px)
On mobile devices, vertical scroll snap is disabled to prevent conflicts with browser chrome (address bar auto-hiding/resizing) and to allow vertical content stacking.
- **CSS Setup:**
  ```css
  @media (max-width: 767px) {
    html.homepage-snap {
      scroll-snap-type: none;
      height: auto;
      overflow-y: visible;
    }
    
    .snap-section {
      height: auto;
      scroll-snap-align: none;
      overflow: visible;
    }
    
    .separator-video-container {
      height: auto;
      aspect-ratio: 21 / 9;
      scroll-snap-align: none;
    }
  }
  ```

### 3. Mode-Adaptive Background Colors
To alternate dark and light sections seamlessly, we bind colors to CSS variables (`var(--bg)`, `var(--fg)`, `var(--surface)`, `var(--surface-2)`).
- **Hero (Section 1):** Always cinematic Dark.
- **Manifesto (Section 2) & About Us (Section 4):** Follows the global theme mode.
- **The Collection (Section 3):** High-contrast Inverted mode (Dark in Light Mode, Light in Dark Mode).
- **CSS Mapping Rules:**
  ```css
  /* Base Dark Styling used by Hero & Collection (in Light mode) */
  .section-dark {
    background-color: #0C0C0C;
    color: #EDEBE5;
    --bg: #0C0C0C;
    --fg: #EDEBE5;
    --surface: #1A1A1A;
    --surface-2: #242424;
    --border: rgba(237, 235, 229, 0.10);
    --muted: rgba(237, 235, 229, 0.50);
  }

  /* Base Light Styling used by Manifesto & About Us (in Light mode) */
  .section-light {
    background-color: #EDEBE5;
    color: #0C0C0C;
    --bg: #EDEBE5;
    --fg: #0C0C0C;
    --surface: #F5F4F0;
    --surface-2: #E5E3DD;
    --border: rgba(12, 12, 12, 0.10);
    --muted: rgba(12, 12, 12, 0.50);
  }

  /* Collection Inversion: When global dark mode is active, Collection becomes Light */
  html.dark-mode .section-collection {
    background-color: #EDEBE5;
    color: #0C0C0C;
    --bg: #EDEBE5;
    --fg: #0C0C0C;
    --surface: #F5F4F0;
    --surface-2: #E5E3DD;
    --border: rgba(12, 12, 12, 0.10);
    --muted: rgba(12, 12, 12, 0.50);
  }
  ```

## Separator Video Player Implementation

### 1. Structure and Dimensions
- **Desktop:** Full-bleed `100vw` width and `33.333vh` height.
- **Mobile (below 767px):** Scales to a clean `21:9` (or `2.33:1`) aspect ratio to avoid video cropping.
- **CSS implementation:**
  ```css
  .separator-video-container {
    position: relative;
    width: 100%;
    overflow: hidden;
    aspect-ratio: 21 / 9; /* Mobile default */
  }

  @media (min-width: 768px) {
    .separator-video-container {
      height: 33.333vh;
      aspect-ratio: auto; /* Overridden by fixed height */
    }
  }
  ```

### 2. Video Player Integration
- **Liquid Customizer Sourcing:** Configured in `sections/hero-canvas.liquid` with up to 3 custom text fields for MP4 video URLs.
- **HTML Mount Point:**
  ```html
  <div 
    id="separator-video-root" 
    class="separator-video-container"
    data-video-playlist="[
      {%- if section.settings.separator_video_1 != blank -%}'{{ section.settings.separator_video_1 }}'{%- else -%}'{{ 'F1_car_slides_on_surface_202606011707.mp4' | asset_url }}'{%- endif -%},
      {%- if section.settings.separator_video_2 != blank -%}'{{ section.settings.separator_video_2 }}'{%- else -%}'{{ 'Formula_1_car_approaches_camera_202606011705.mp4' | asset_url }}'{%- endif -%},
      {%- if section.settings.separator_video_3 != blank -%}'{{ section.settings.separator_video_3 }}'{%- else -%}'{{ 'Formula_1_car_braking_and_202606011705.mp4' | asset_url }}'{%- endif -%}
    ]"
  ></div>
  ```
- **React Mounting:** Mounted in `src/main.tsx` reusing the existing `VideoBackground` component which handles double-buffered cross-fades (fading active video opacity 1 -> 0 and inactive video opacity 0 -> 1 over 800ms) and listens for `pitwall:mute` event transitions.

## Dynamic Product Card Rotation Logic

### 1. Sourcing Shopify Collection Data
We can render the collection's product data into a JSON script tag in `sections/hero-canvas.liquid`:
```html
<script id="collection-products-data" type="application/json">
  [
    {% for product in collections[section.settings.collection].products limit: 20 %}
      {
        "title": {{ product.title | json }},
        "url": {{ product.url | json }},
        "price": {{ product.price | money | json }},
        "image": {{ product.featured_image | img_url: '600x' | json }},
        "specs": {{ product.metafields.custom.specs | default: "1:18 SCALE / PRECISION DETAIL" | json }}
      }{% unless forloop.last %},{% endunless %}
    {% endfor %}
  ]
</script>
```
- **Fallback Array:** If the JSON data is empty (no collection selected or empty catalog), a hardcoded fallback array containing 6 mock product assets will be used.

### 2. Auto-Rotation and De-duplication Strategy
To display 5 product cards (4 square, 1 tall spanning 2 rows) without duplicate products visible at any time:
- Mount a `CollectionGrid` React component on `#collection-grid-root`.
- Let $N$ be the total number of products. The grid distributes products into the 5 card slots at step $S$:
  - Card $i$ (for $i \in \{0, 1, 2, 3, 4\}$) displays product at index `(i + S * 5) % N`.
- A global timer ticks every 5-7 seconds, incrementing $S$, which causes all cards to cross-fade to their next product.

### 3. Hover Interactions
- **Overlay Preservation:** When a user hovers on Card $i$, the global timer pauses (rotation halts), and the details overlay slides up.
- **Visuals:** The details overlay contains the product title, specs, price, and racing-yellow highlight states. On mouse leave, the timer resumes.
- **Fade Animation:** A simple CSS transition on opacity over a 500ms duration provides a smooth cross-fade when cycling products.
