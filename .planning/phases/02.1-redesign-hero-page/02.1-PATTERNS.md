## Target Files

### 1. [MODIFY] `sections/hero-canvas.liquid`
- **Role:** Main homepage template section hosting Liquid markup, settings schemas, and React mounting wrappers.
- **Data Flow:** Sourced from theme customizer settings and collection data; serializes products as JSON and feeds them into data attributes.
- **Analog:** `sections/page-about.liquid` (for schema structure) and current `sections/hero-canvas.liquid` (for styling references).
- **Code Pattern (Customizer Settings):**

  ```liquid
  }

  ```

### 2. [MODIFY] `src/main.tsx`
- **Role:** Client-side React bootstrapper and mounting script.
- **Data Flow:** Selects DOM nodes by ID, reads customizer configurations from `data-*` attributes, and mounts the React components.
- **Analog:** Current mounts in `src/main.tsx` (e.g. `car-canvas-root` and `hero-video-root`).
- **Code Pattern (Islands Mounting):**
  ```typescript
  const separatorVideoRoot = document.getElementById('separator-video-root');
  if (separatorVideoRoot) {
    let playlist: string[] = [];
    try {
      const dataPlaylist = separatorVideoRoot.getAttribute('data-video-playlist');
      if (dataPlaylist) {
        playlist = JSON.parse(dataPlaylist.replace(/'/g, '"'));
      }
    } catch {
      playlist = [];
    }
    const root = ReactDOM.createRoot(separatorVideoRoot);
    root.render(<VideoBackground playlist={playlist} />);
  }
  ```

### 3. [NEW] `src/components/CollectionGrid.tsx`
- **Role:** High-performance React component managing the dynamic rotating 3-column product grid.
- **Data Flow:** Accepts serialized products array, handles global interval tick, rotates item indexes safely, and renders individual cards with details overlay.
- **Analog:** `src/components/VideoBackground.tsx` (for double buffering / interval hooks) and `src/components/FeaturedCarousel.tsx` (for card structures).
- **Code Pattern (Deduplicated Index Rotation):**
  ```tsx
  import React, { useState, useEffect } from 'react';
  import { motion, AnimatePresence } from 'motion/react';

  interface Product {
    title: string;
    url: string;
    price: string;
    image: string;
    specs: string;
  }

  export function CollectionGrid({ products }: { products: Product[] }) {
    const [step, setStep] = useState(0);
    const [isHovered, setIsHovered] = useState(false);

    useEffect(() => {
      if (isHovered || products.length <= 5) return;
      const interval = setInterval(() => {
        setStep((prev) => prev + 1);
      }, 6000);
      return () => clearInterval(interval);
    }, [isHovered, products]);

    const getProduct = (slotIndex: number) => {
      if (products.length === 0) return null;
      const index = (slotIndex + step * 5) % products.length;
      return products[index];
    };
    
    // Render the cards using motion.div with absolute-positioned layers for fade
  }
  ```
