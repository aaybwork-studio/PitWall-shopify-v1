## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.3-03-01 | XSS | foundingStory, brandParagraph rendered in JSX | mitigate | React text nodes are auto-escaped — no dangerouslySetInnerHTML used; prop values rendered as `{foundingStory}` not as HTML |
| T-02.3-03-02 | XSS | ctaUrl in href attribute | mitigate | React sets href as a DOM attribute; javascript: protocol URLs are blocked by React's href sanitization in React 16+; Shopify's `url` schema type further restricts to valid URLs |
| T-02.3-03-03 | Spoofing | CTA link to /pages/about | accept | Internal relative URL — no open redirect surface; ctaUrl defaults to /pages/about |
| T-02.3-03-04 | Information Disclosure | telemetry SVG in Panel 2 | accept | SVG contains no user data — all values are hardcoded coordinates |
